# Compass

Compass is the HN Group browser. Its own directional compass mark uses HN purple and lavender, independently of the HN monogram.

- `compass.svg`: rounded app icon, for desktop, launchers and compact product placements.
- `compass-mark.svg`: transparent standalone mark.

Canonical editable SVGs live here. Browser packaging renders PNG/ICO from its copy of `compass.svg`; App Manager and Downloads use the same artwork. Keep the original browser bundle, profile, protocol and encryption identities for compatibility; those technical identifiers are not the product name.
