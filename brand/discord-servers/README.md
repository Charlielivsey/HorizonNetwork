# Discord server icons

Made at the user's request (5 November 2026), each its own design around the approved, unaltered logo from
`brand/logos/`. 1024 × 1024 PNG; Discord crops them to a circle, so everything important sits inside it.

| Server | File | Design |
| --- | --- | --- |
| Horizon Network HQ | `horizon-network-hq.png` | Navy, a ring in the HN stripe colours, stacked white wordmark, purple HQ badge |
| Horizon Advertising | `horizon-advertising.png` | Lavender, broadcast waves rippling out from the white HA roundel |
| Horizon Development | `horizon-development.png` | Purple blueprint grid, yellow code brackets around the white HD roundel |
| Horizon Network \| Staff Server | `horizon-network-staff.png` | Teal to navy, stacked white wordmark, yellow STAFF badge |

To remake them (needs Playwright): `node brand/discord-servers/make-icons.cjs` (it writes the PNGs here).
