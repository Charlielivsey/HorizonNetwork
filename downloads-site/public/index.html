GOOD TO KNOW

Private by design

All of your internet traffic goes through HN Group’s UK server while you’re connected. Your computer makes its own key, your password is never saved, and HN Browser can control the same connection.

Preview builds aren’t signed yet. On a Mac, right-click the app and choose Open the first time; on Windows, choose More info → Run anyway if SmartScreen asks; on Linux, allow the AppImage to run as a program (or install it with App Manager).
