How it works

Your password is typed here and handed once to the SSH window that opens; it is never saved or put on a command line. SSH keys on this PC are never read or offered. The first time, HN Secure Network shows the server’s fingerprint for you to check; after that it refuses to connect if the server’s identity ever changes.
