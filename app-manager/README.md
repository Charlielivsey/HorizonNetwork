# HN Group App Manager

Desktop app for macOS (Apple silicon and Intel) and Windows 10/11 x64. HN Browser itself currently requires Apple silicon on Mac. Run with Node 24: `npm ci`, `npm start`. Verification: `npm test` and `xvfb-run -a npm run test:desktop` on Linux. `npm run icons` prepares the original HN Group icon; `npm run build:mac` / `npm run build:win` build installers on the matching OS.

The manager detects the two applications using their bundle identifiers in `/Applications` and `~/Applications`, or their exact Windows uninstall registry entries (including custom install locations). Mac installs go to `~/Applications`; updates retain an existing location. Existing apps must be quit, including their tray/menu bar icon, before changing preferences, updating or removing them. It never kills a process or reads account credentials, browser data, SSH secrets or WireGuard keys. Settings apply on next launch. Unknown preferences are preserved.

HN Browser settings cover themes, HN website themes, animations, startup/tabs, search, privacy, downloads and locking/VPN startup. Windows Secure Network settings cover theme, login startup and connect-on-launch. On Mac, SSH username is available; Secure Network 2.4.1 adds login startup through a narrow command-line mode that invokes SMAppService inside its own installed bundle. If the app is running, close it and reopen settings to make that control available. Account/device/WireGuard controls remain inside the applications.

Only strictly validated assets from `https://downloads.hngroup.org.uk/api/releases` can be installed. Downloaded bytes are size/SHA-256 checked and checked again immediately before installation. Downloads can be cancelled; app installation cannot. macOS ZIPs are checked for paths, escaping symlinks, bundle ID, version and ad-hoc code signature, then staged beside the target with backup/rollback. Protected Applications folders use macOS's administrator prompt. Windows runs the verified NSIS installer, and uses only an uninstaller within the registered installation directory. Removing a Mac app moves it to Trash; removing either app preserves account data. Disconnect Secure Network first: removing its UI does not remove WireGuard, its helper or VPN configuration.

The isolated renderer has no Node or general filesystem/shell bridge; main process IPC checks the sender and its top-level local document. Desktop tests run with native changes disabled and a temporary profile. `.github/workflows/app-manager.yml` builds a universal Mac ZIP/DMG and Windows x64 installer, publishes a preview release and records platform manifests for the downloads site. Preview installers are not developer-signed/notarised. App Manager checks its own release version and links to its download when newer.

Real install/uninstall, macOS login-item approval and Windows registry/NSIS behavior require native hardware validation; Linux tests do not claim to exercise these OS services.
